# See agents/AGENTS.md

This project's standing instructions for AI coding agents live in
[`agents/AGENTS.md`](agents/AGENTS.md) — [`agents/README.md`](agents/README.md)
explains why they're in a subdirectory rather than here. This file exists so
that tools (such as Codex) which specifically look for `AGENTS.md` at the
repository root find their way there.

Read `agents/AGENTS.md` before making any change here. If you're picking up
a task autonomously from [`ROADMAP.md`](ROADMAP.md), the full procedure is
[`agents/workflows/roadmap-task.md`](agents/workflows/roadmap-task.md).
