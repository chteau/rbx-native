      Installing it

      After you download
      1. Unzip it into the themes folder, so you get themes//manifest.json:
        • Linux and macOS: ~/.config/rbx-native/themes/
        • Windows: %APPDATA%\rbx-native\themes\
      2. In RbxNative, open Settings › Appearance › Theme and click its card. No restart needed.
      3. To share it, put the folder's files in a GitHub repository. Anyone can then use Install from GitHub with the repository link.
