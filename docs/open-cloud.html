Roblox key

Optional. Only for the stuff Roblox requires auth for.

Most of RbxNative works without a Roblox account. A key is for publishing, My Games, version history, DataStores, and downloading plugins from the store.

Making a key

  1. Sign in to the Creator Dashboard and open API Keys, under Open Cloud. Click Create API Key and name it RbxNative.
  2. Under Access Permissions, pick an API from the dropdown, click Add API System, then pick its operations in the box on the right. Do that for each API below.
  3. Under Security you can type your IP address and pick an expiration date. Both are optional. With an IP set, the key only works from that internet connection, so a stolen key is useless. But if your IP changes (new Wi-Fi, VPN, a router reboot on some providers), RbxNative gets refused until you add the new one.
  4. Click Save & Generate Key, then Copy Key To Clipboard. Roblox only shows it once.

Which scopes

Three are needed for the basics. Everything else switches one feature on, and the editor tells you which scope is missing when a feature needs it.

Want everything to just work? Add every API like this. You can leave the Restrict toggles off, or turn them on and pick your games so the key can't touch anything else.

Adding it

Paste it in the first-run setup or later under Home, Manage key. It goes in your OS keyring.

For scripts and CI, rbxcloud and the editor also read these, in this order:

  1. The RBX_API_KEY environment variable.
  2. A plain text file at ~/.config/rbx-native/api_key. Run chmod 600 on it, the loader warns you if other users can read it.

Never commit a key, in this repo or any other.

Signing in

Separate from the key. Play, Team Create and presence use a Roblox sign-in, done by code from the first-run setup or Settings, Account.
