Install

Windows, macOS and Linux. Installs for you only, no admin, and keeps itself up to date.

From a terminal

One line. It grabs the latest release, checks it against the signed checksums and installs it.

macOS and Linux:

curl -fsSL https://rbxnative.chteau.bzh/install.sh | sh

Windows, in PowerShell:

irm https://rbxnative.chteau.bzh/install.ps1 | iex

Where it goes:

  • Linux: ~/.local/share/rbxnative, a rbxnative command in ~/.local/bin, and an app menu entry that opens .rbxl and .rbxlx files.
  • macOS: ~/Applications/RbxNative.app. Apple Silicon only.
  • Windows: %LOCALAPPDATA%\Programs\RbxNative with a Start menu shortcut, the same folder the setup uses.

If minisign is installed, the script also checks the checksums' signature, with the same key the updater uses. Without it, it still checks the hash.

A specific version:

curl -fsSL https://rbxnative.chteau.bzh/install.sh | sh -s -- --version 0.2.0
$env:RBXNATIVE_VERSION = '0.2.0'
irm https://rbxnative.chteau.bzh/install.ps1 | iex

Removing it again. That only takes what the script added, your settings, places and saved keys stay.

curl -fsSL https://rbxnative.chteau.bzh/install.sh | sh -s -- --uninstall
$s = irm https://rbxnative.chteau.bzh/install.ps1
& ([scriptblock]::Create($s)) -Uninstall

Want to read it first? install.sh and install.ps1. They're also attached to every release.

Installers

Rather click through something? The latest release has these:

SystemFileWhat it does
Windows 10/11 x64Setup (.exe)Per-user install, Start menu entry, optional desktop shortcut, opens .rbxl and .rbxlx. Uninstall from Settings, Apps.
macOS, Apple SiliconDisk image (.dmg)Drag RbxNative to Applications.
Linux x86_64AppImageOne file. Make it executable and run it. Updates replace the file.

None of them are signed with a paid certificate yet, so the first launch gets a warning:

  • Windows SmartScreen says "Windows protected your PC". Click More info, then Run anyway.
  • macOS says it can't check the app. Right-click RbxNative in Applications, Open, then Open again. The terminal install skips this.
  • The AppImage needs FUSE, most desktops have it. If not, run it with --appimage-extract-and-run.

Portable

Every release also has a plain zip (Windows) or tarball (macOS, Linux). Unpack it anywhere you can write to and run it from there, nothing else to install.

curl -LO https://github.com/chteau/rbx-native/releases/download/v0.2.0/RbxNative-0.2.0-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/chteau/rbx-native/releases/download/v0.2.0/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS

tar xzf RbxNative-0.2.0-x86_64-unknown-linux-gnu.tar.gz
./RbxNative-0.2.0-x86_64-unknown-linux-gnu/rbxnative

Swap the version for the latest one. 0.1.0 called the program rbxstudio. An old install renames itself when it updates and keeps rbxstudio as a link.

X11 is the main target on Linux. Wayland works but the cursor doesn't get captured, so anything that needs pointer lock won't feel right.

Updates

RbxNative updates itself. On launch it checks the latest GitHub release in the background, downloads a newer one, checks the minisign signature and the hash, and swaps it in for the next launch. Nothing blocks startup, and offline it just moves on.

That works for every install above: the setup, the terminal install, the portable folder, the app in Applications and the AppImage.

The switch and a Check now button are in Settings, Files & recovery, Updates. It stays off when the install folder isn't writable, in a Flatpak, and in dev builds.

Build from source

You need Rust 1.96 or newer from rustup.rs. First build takes a while, it's a big project.

# Debian/Ubuntu
sudo apt install libxkbcommon-x11-dev libx11-xcb-dev libssl-dev libfontconfig1-dev

git clone https://github.com/chteau/rbx-native
cd rbx-native
cargo build --release -p rbx_studio --bin rbxstudio
./target/release/rbxstudio

That package list comes from real setups, not a full audit. If your distro needs something else, open an issue or a PR. If a build fails deep in a dependency, check that rustc -V is the toolchain rustup installed and not an older one earlier in PATH.

Flatpak

The Flatpak builds from source the way Flathub wants it. It isn't on Flathub yet, so for now you build it yourself, the packaging readme has the steps.

Things that have to run programs on the host aren't in that build: the network simulator, the controller emulator and device simulation in Sober. The app says so where they'd be.
