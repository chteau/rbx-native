Install

Linux x86_64 for now. macOS and Windows releases are upcoming.

Download

The latest release has a tarball, nothing to install system-wide.

curl -LO https://github.com/chteau/rbx-native/releases/download/v0.1.0/rbxstudio-0.1.0-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/chteau/rbx-native/releases/download/v0.1.0/SHA256SUMS
sha256sum -c SHA256SUMS

tar xzf rbxstudio-0.1.0-x86_64-unknown-linux-gnu.tar.gz
cd rbxstudio-0.1.0-x86_64-unknown-linux-gnu
./rbxstudio

X11 is the main target. Wayland works but the cursor doesn't get captured, so anything that needs pointer lock won't feel right.

Updates

RbxNative updates itself. On launch it checks the latest GitHub release in the background, downloads a newer one, checks the minisign signature and the hash, and swaps it in for the next launch. Nothing blocks startup, and offline it just moves on.

The switch and a Check now button are in Settings, Files & recovery, Updates. It stays off when the install folder isn't writable, in a Flatpak, and in dev builds.

Build from source

You need Rust 1.96 or newer from rustup.rs. First build takes a while, it's a big project.

# Debian/Ubuntu
sudo apt install libxkbcommon-x11-dev libx11-xcb-dev libssl-dev libfontconfig1-dev

git clone https://github.com/chteau/rbx-native
cd rbx-native
cargo build --release -p rbx_studio --bin rbxstudio
./target/release/rbxstudio

That package list comes from real setups, not a full audit. If your distro needs something else, open an issue or a PR. If a build fails deep in a dependency, check that rustc -V is the toolchain rustup installed and not an older one earlier in PATH.

Flatpak

The Flatpak builds from source the way Flathub wants it. It isn't on Flathub yet, so for now you build it yourself, the packaging readme has the steps.

Things that have to run programs on the host aren't in that build: the network simulator, the controller emulator and device simulation in Sober. The app says so where they'd be.
