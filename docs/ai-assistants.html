Use RbxNative with Claude

Connect Claude, Cursor or VS Code to the place you have open.

RbxNative has an MCP server, like the one built into Roblox Studio. Once it's on, an AI assistant can read and edit your scripts, run Luau, start a playtest, read the Output and grab a screenshot of the viewport, in the place you have open right now.

Beta. The server is off by default. Every edit it makes is a normal undo step, so Ctrl+Z works on it like on your own edits.

Turn it on

  1. Open Settings (Alt+S), go to AI assistants (also File, Connect an AI Assistant).
  2. Switch on MCP server and restart RbxNative when it asks.
  3. Back on that page it should say Running. Pick your client there and hit Copy: the setup it shows already has the right path for your install, so it's the easiest way.

The rest of this page is the same thing by hand.

The command

Your AI client starts rbxnative --mcp, a small bridge that talks to every RbxNative window you have open. It's a stdio server, there's no URL or port to type in. Most clients want the full path to the program:

Installed withCommand
install.sh (Linux)~/.local/bin/rbxnative --mcp
Flathubflatpak run io.github.chteau.rbx_native.Editor --mcp
install.sh (macOS)~/Applications/RbxNative.app/Contents/MacOS/RbxNative --mcp
install.ps1 (Windows)%LOCALAPPDATA%\Programs\RbxNative\RbxNative.exe --mcp

JSON config files don't expand ~ or %LOCALAPPDATA%, so write the path out in full there (/home/you/..., or C:\\Users\\you\\... on Windows, backslashes doubled). The AI assistants page does this for you.

Claude Code

One command in a terminal, it adds the server for all your projects:

claude mcp add --scope user rbx-native -- ~/.local/bin/rbxnative --mcp

Then claude mcp list should show rbx-native as connected. Swap the path for yours from the table above.

Claude Desktop

The easy way: on the AI assistants page pick Claude Desktop and click Add to Claude Desktop. It backs up your config first, keeps your other servers, and tells you what it changed. Then quit Claude Desktop fully and open it again.

By hand, open the config file (Claude Desktop, Settings, Developer, Edit Config) and add rbx-native under mcpServers:

{
  "mcpServers": {
    "rbx-native": {
      "command": "/home/you/.local/bin/rbxnative",
      "args": ["--mcp"]
    }
  }
}
SystemConfig file
macOS~/Library/Application Support/Claude/claude_desktop_config.json
Windows%APPDATA%\Claude\claude_desktop_config.json
Linux (community builds)~/.config/Claude/claude_desktop_config.json

If you installed Claude Desktop from the Microsoft Store, its file lives under %LOCALAPPDATA%\Packages\Claude_...\LocalCache\Roaming\Claude\ instead. The button finds that one on its own.

Cursor

Same JSON as Claude Desktop, in ~/.cursor/mcp.json (Settings, MCP, Add new global MCP server opens it).

VS Code

Save this as .vscode/mcp.json in your project, or run MCP: Open User Configuration and merge it there. Copilot Chat lists the tools in Agent mode.

{
  "servers": {
    "rbx-native": {
      "type": "stdio",
      "command": "/home/you/.local/bin/rbxnative",
      "args": ["--mcp"]
    }
  }
}

Other clients

Anything that can launch a stdio MCP server works: command is the path above, argument is --mcp. If you set XDG_CONFIG_HOME yourself, pass the same value to the client (an env block) so the bridge finds the editor.

Checking it works

Hit Test connection on the AI assistants page. It runs the bridge exactly like a client would and tells you if it reached this window. Once your client makes its first call, the page shows it as attached.

Then ask your assistant something like "list the scripts in ServerScriptService" or "what's in the Output?". If it says no editor is serving MCP, the place isn't open or the server switch is off.

What it can do

GroupWhat for
Explore the placeSearch the tree, inspect any instance's properties, tell open windows apart
ScriptsRead, search and grep every script, edit them (one undo step per edit)
Run LuauIn the edited place, or a playtest's client or server
PlaytestStart and stop Play, read the Output, screenshot the viewport, walk the character, type and click
AssetsSearch the Creator Store, insert models, upload images (needs your Open Cloud key)
Docs and guidesRoblox's creator docs, plus built-in guides on scripting, UI style, monetization, performance and more
SaveSave, or Save As to a new file

Tool names match Roblox Studio's own MCP server, so prompts written for Studio work here too. Studio's AI generation tools are listed but can't run, Roblox has no public API for them, and they say so. With several windows open, the assistant picks one by its studio id (list_roblox_studios).
