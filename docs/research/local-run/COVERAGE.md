# Local Run coverage

Generated by `cargo run -p rbx_sim --example coverage -- docs/research/local-run/COVERAGE.md` from `assets/API-Dump.json`, by security level. Each member counts once, under the class that declares it. Each place a script runs gets a probe: a server script in a fresh Local Run for game scripts (security `None`), a plugin in the plugin host for plugins (`PluginSecurity`), and a Command Bar run for `LocalUserSecurity`. The probe makes an instance of each class (or of its first creatable subclass, or asks the API that hands one out) and indexes every member; it counts as there when that gives a value, not an error or nil.

The same probe ran in real Studio 0.748's Command Bar (`--studio-probe`, then `--import-studio` on Studio's log, kept in `studio-reach.tsv`). The Command Bar runs at identity 4 and reaches every `PluginSecurity` and `LocalUserSecurity` member whose instance a script can get (`PluginManager():CreatePlugin()` hands it a `Plugin`); the member lists below mark with † what Studio didn't reach either (`IXPService` isn't a service there, `File`, `PluginConnection` and the like aren't handed out).

Read the property numbers with care: any property the reflection database knows reads back as data (its saved value or default), whether or not the runtime acts on it. What the sim actually simulates is listed in `PLAN.md`. Functions and events count when they exist, whether or not the runtime acts on them.
