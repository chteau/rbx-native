Plugins

Real Studio plugins, plus native ones.

RbxNative runs real Roblox Studio plugins, and its own native ones in Luau or WebAssembly. Most community plugins run, F3X and Archimedes both work.

Installing from the store

Open Manage Plugins, Popular plugins (also Plugins, Popular on the ribbon). It lists free Creator Store plugins verified to run here. Install downloads it and starts it right away, Uninstall stops it and deletes the file.

The search finds any other free plugin, those just weren't tested. Downloads need your Open Cloud key, Roblox refuses anonymous plugin downloads. Paid plugins are never offered.

Where they load from

  • RbxNative's own folder, ~/.config/rbx-native/plugins (or RBX_STUDIO_PLUGINS_DIR).
  • Studio's Plugins folder, including the one in a Vinegar prefix, unless you switch that off in Manage Plugins.

A .lua or .luau file runs as one Script. A .rbxm or .rbxmx runs every enabled Script in it. Each plugin gets its own Luau VM, and the manager shows the last error that stopped one from loading.

Writing a native plugin

One folder per plugin in the plugins folder, with a plugin.toml. There are examples in examples/plugins, and the full reference is in docs/plugins.md.
