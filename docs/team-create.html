Team Create

Work next to people in Studio, through a plugin.

Real Team Create isn't happening, that part belongs to Roblox. What exists is a Studio plugin that talks to RbxNative through a relay.

Setting it up

RbxNative has its side built in, only people in Studio need the plugin.

Get the Studio plugin Download .rbxmx

  1. Install it from the Creator Store (it shows up in Studio's Toolbox, Plugins), or drop TeamPresence.rbxmx in Studio's plugins folder (Plugins tab, Plugins Folder) and restart Studio.
  2. Allow the HTTP requests when it asks.
  3. Everyone opens the same place. Each side needs to be signed in to Roblox.

What you get

Each side sees the other's camera, selection and open script. Presence is end-to-end encrypted with a key derived from the place, so the relay only ever sees ciphertext.

Live co-editing (beta)

Off by default. Turn on Beta Features, Live co-editing in RbxNative, and the Co-edit toggle in the plugin for people in Studio.

It shares property changes, inserts, deletes, reparenting, renames and script text. Remote edits are their own undo steps, concurrent script edits merge with conflicts kept side by side, and someone joining late catches up from the relay's log.

It's beta. Save your work somewhere that isn't only the live session.
