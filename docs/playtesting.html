Playtesting

Hit Play and the game runs embedded in the editor.

Roblox's client doesn't run natively on Linux, so Play goes through Sober or Roséline. Install one of them separately.

Setup

flatpak install flathub org.vinegarhq.Sober

Roséline works too, its app id is net.buwryy.Roseline. You also need to be signed in to Roblox, from the first-run setup or Settings, Account.

Which client runs

  • Sober goes first when it's installed.
  • No Sober, Play uses Roséline.
  • If Sober says it can't join, for example while it's waiting on an update for a new Roblox version, the test opens in Roséline instead when you have it.

Before each Play the editor checks whether your client has a newer build and installs it. You'll see "Updating Sober…" on the button and a line in Output.

Good to know

  • In Roséline, Roblox's own menus stay the desktop ones. Output says so.
  • The Flatpak build of RbxNative leaves out the network simulator, controller emulator and Sober device simulation.
