Command line

The tools that come with a source build.

The release tarball ships rbxstudio. cargo build --release from a source checkout builds the rest.

BinaryWhat it does
rbxstudioThe editor. rbxstudio [--select <name-or-path>] [--run <script.luau>] [--verbose] <place>, --help for the rest
rbxviewStandalone 3D viewer, rbxview place.rbxl [--screenshot out.png]
rbxdumpPrints a file's instance tree. --roundtrip <file> writes it back and diffs it
rbxluaRuns Luau against a place, or its TestEZ specs with rbxlua test place.rbxl
rbxauditChecks scripts for remote security problems, exits 1 on any High so it fits in CI
rbxcloudSmall Open Cloud CLI: whoami, list, download, asset

MCP server (beta)

Turn on Settings, Beta features, MCP server, then point your AI client at rbxstudio --mcp. It can read and edit the place the editor has open, through the same tools Roblox's Studio MCP server names.
