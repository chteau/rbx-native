Features / UI

Figma import

Paste a Figma frame link and get a real ScreenGui.

In the UI Editor, the canvas's + menu › Import from Figma. Connect once through your browser, paste a frame link, and the frame lands under the open ScreenGui as one undo step.

How it converts

  • Classes are inferred: a frame with a click reaction becomes a TextButton, a text field a TextBox, an image fill an ImageLabel, an overflowing clip a ScrollingFrame.
  • Constraints become position, size and anchor. Auto layout becomes UIListLayout and UIPadding.
  • Corners, strokes, gradients and drop shadows come along.
  • Vector-only groups are rendered to one image.

Limits

  • You need a Figma account, and image fills get uploaded as decals with your Open Cloud key.
  • Figma sign-in needs the app's secret built in. Release builds don't have it yet, so for now it only works in a build made with RBX_FIGMA_CLIENT_SECRET set, and it tells you so otherwise.
  • Uncertain guesses are listed for review before the import lands.
