Features / Animation and avatars

Animation Editor

Key, curve and preview animations on R15, R6 and Avatar Joint Upgrade rigs.

Avatar › Animation opens the Animation Editor as its own tab, laid out like Blender's Animation workspace: the rig on its own stage with a floor grid, a dope sheet of the joints and a playback bar.

How to use it

  • Key joints at the playhead, select, drag, copy and delete keys, pick their easing, add animation events.
  • Select a limb to get Move or Rotate handles on its joint. R switches between them, like Studio.
  • IK posing (Body Part or Full Body, with pinned parts).
  • The Curve Editor has per-channel curves with tangent handles and Generate Curve.
  • Face channels (FACS) keyed from sliders.
  • Clips save as KeyframeSequences (or CurveAnimations) in ServerStorage.RBX_ANIMSAVES, like Roblox's editor.
  • Right-click any Animation in the Explorer › Play Animation to download a published animation and play it on that rig.

Compared to Studio

  • Unsaved work is kept as a local draft and offered back when you reopen the rig.
  • Playback never touches the undo history, and the rig is saved at rest.
