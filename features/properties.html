Features / Editing and building

Properties

Real widgets per type, sliders, sequence editors, image and sound previews.

Every property type gets its own widget: checkboxes, colour pickers, enum dropdowns, vectors, CFrame as Position and Orientation, UDim2, Rect, PhysicalProperties, Font, references and asset URIs. Categories follow Studio's own order, and properties Studio hides stay hidden.

How to use it

  • Number fields can be dragged to scrub the value. Bounded ones (Transparency, ClockTime, a GUI's Rotation) get a slider next to the field.
  • Click a NumberSequence or ColorSequence to open a curve or gradient editor in its own little window. Drag keypoints, click empty space to add one.
  • Reference properties like a Weld's Part0: click the value, then click an instance in the Explorer or the 3D view. Escape backs out, × clears it.
  • Image ids show the image's resolution, and hovering shows the image. A SoundId gets a Preview row with play, pause and a seek bar.
  • Select several instances and edit a shared property once, it's one undo step.
  • The filter box at the top searches properties, attributes and tags.

Compared to Studio

  • A BrickColor and the numbers Studio computes (like a part's Origin) show and can be typed in.
  • Sound preview plays at the instance's Volume and changes nothing in the place.

Limits

  • Which properties have a slider is a hand-made table, since Roblox's API dump has no ranges. The field still takes any value.
