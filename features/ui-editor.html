Features / UI

UI Editor

A Figma-style canvas for StarterGui, instead of typing UDim2s.

Select a ScreenGui (or anything in it) and open the UI Editor tab. That screen is drawn alone on a canvas, by the same GUI renderer as the 3D view, at a device preset or a size you type.

How to use it

  • Click or marquee to select, then drag, resize and rotate. Arrows nudge, Alt shows distances, smart guides snap to siblings and the parent.
  • The insert bar draws elements: pick a tool (F, T, B, X, L, G) and drag it out. A switch picks whether the canvas writes Offset or Scale.
  • The design panel has position with an anchor grid, size with an aspect lock, auto layout, opacity, corner radius (per corner too), fill with gradients, stroke, effects and constraints. Values that Roblox keeps on a modifier create the UICorner, UIStroke, UIPadding or layout for you.
  • Align, distribute and group, and the Stylesheet sub-tab keeps Roblox's style sheets.

Compared to Studio

  • Studio edits UI in the 3D view with Properties. This works like a design tool, every scrubbable label and all.
  • Drop shadows (UIShadow) have Figma's Effects section, and upgraded UI gradients render.
