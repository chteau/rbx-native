Features / Collaboration

Branch and merge places

Three-way merge of place files, with real conflict resolution.

A place here is a local file you can branch in git like any other. rbxmerge merges two versions of a place against their common base.

How it works

  • Instances are matched by UniqueId, and every property, attribute, tag and script line merges on its own.
  • Conflicts come out structured, not as conflict markers in a binary file.
  • rbxmerge plugs into git as a merge driver.
  • File › Merge Place opens a resolver window in the editor for whatever it couldn't settle.

Compared to Studio

  • Studio has no way to merge two copies of a place.
