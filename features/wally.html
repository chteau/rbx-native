Features / Scripting

Wally packages

Search and install Wally packages straight into the place.

The Wally dock (next to Output while the Script Editor is open) searches the real api.wally.run registry.

How to use it

  • Search, pick a package, and it resolves the whole dependency graph like Wally does.
  • It installs into the place as one undo step, in Wally's own layout under Packages/_Index, with alias modules.
  • A Recently published list shows the newest packages.
  • Connected to Argon? Installs reach your project too.

Limits

  • An unsatisfiable requirement errors out instead of installing the wrong version.
