Quick Open and command palette

Jump to any instance or any command from the keyboard.

  • Ctrl+P (View › Quick Open) finds any instance by name or path. A script opens in the Script Editor, anything else gets selected.
  • Ctrl+Alt+P (View › Command Palette), or typing > in Quick Open, finds any command: menu items, transform tools, ribbon commands, and a Focus command for every dock.

Results rank prefixes first, then word starts, then scattered letters, with your recent picks on top, and each row shows its shortcut.
