Features / Cloud and publishing

Save and publish to Roblox

Upload to Roblox from the File menu, or make a new experience.

File › Save to Roblox and Publish to Roblox upload the open place as a new saved or live version.

How to use it

  • A place opened from Home is already linked. Any other file picks its game once and remembers it.
  • Every upload asks first, naming the experience and place and whether it goes live.
  • Publish an unlinked file as a New experience: name, description and owner (you or a group).
  • Layers and notes are stripped from the uploaded copy by default.

Limits

  • Needs your Open Cloud key. A refused upload says why in Roblox's own words.

More in the docs: Roblox key.
