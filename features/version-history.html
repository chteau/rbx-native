Features / Cloud and publishing

Version history

Browse, search, open and restore any saved version of a place.

File › Version History lists the linked place's saved and published versions, who saved them and when.

How to use it

  • Search matches the version number, the date (2026-10, oct), who saved it and its notes.
  • Date presets: All time, Today, This week, This month.
  • Open any version as a local copy in a new editor.
  • Restore uploads that version as a new one, like Roblox's own restore.
  • Give a version a local label, since Roblox keeps no names for versions.

Limits

  • Search only covers the pages already loaded. Load more goes further back.
