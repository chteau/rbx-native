Features / Plugins

Studio plugins

Real Roblox Studio plugins run inside the editor. F3X and Archimedes work.

Plugins from Studio's Plugins folder (including a Vinegar prefix on Linux) and from RbxNative's own folder run in their own sandboxed Luau VM, with the plugin API they need.

What works

  • Toolbars and buttons on the Plugins tab, DockWidgetPluginGuis, Selection, ChangeHistoryService, HttpService (each new host asks first), RunService, signals and task.
  • A plugin's Handles and ArcHandles show in the 3D view and can be dragged. An activated plugin gets the mouse.
  • Plugin edits, even from timers, undo like your own.
  • 28 of the 30 most voted free plugins on the Creator Store start and answer their buttons without errors.

Plugin widgets

Every plugin widget is its own dock tab. Drag it to any edge, tab it with Explorer, or tear it out into its own window. It remembers where you put it.

Limits

  • Only an allow-listed part of the plugin API is there. The manager shows the last error that stopped a plugin from loading.
