Features

Everything RbxNative does, one page each. 80 so far.

Every feature that's shipped in RbxNative, each with its own page: what it does, how to open it, how it compares to Studio, and what it can't do yet. Features marked beta are off by default, switch them on in File › Beta Features.

New here? The docs get you from nothing to a place open in the editor.

Editing and building

  • ExplorerThe place's tree, with more editing straight from the rows than Studio gives you.
  • PropertiesReal widgets per type, sliders, sequence editors, image and sound previews.
  • Attributes and TagsAdd, rename and edit attributes and CollectionService tags from Properties.
  • Move, Scale, Rotate and TransformStudio's gizmos with snapping, handle summoning and a live stud readout.
  • Pivot toolsEdit Pivot and Reset Pivot from the Model tab, like Studio.
  • Align toolLine objects up on X, Y and Z, with a live preview.
  • Change ClassTurn a Part into a WedgePart or a Script into a LocalScript without rebuilding it.
  • Sun tool and light guidesPoint at the scene to place the sun, and see how far your lights reach.
  • Select by querySelect every part that matches a query, then edit them all at once.
  • Quick Open and command paletteJump to any instance or any command from the keyboard.
  • Layers and 3D notesHide, lock and solo groups of instances, and pin notes in the 3D view.
  • ToolboxSearch the Creator Store and drop models, meshes, images and audio in.
  • Import 3D models and imagesUpload FBX, OBJ and glTF files as real Roblox assets.
  • Export to glTF, FBX and filesGet your place or selection out as glTF, FBX, .rbxm or .rbxl.
  • Freeze RotationZero out an instance's rotation without it moving, like Blender's Apply Rotation.
  • Input ActionsA table editor for InputContexts, InputActions and InputBindings.

Scripting

  • Script EditorTabs, Luau highlighting, multi-cursor, folding and Go to Definition.
  • Autocomplete and Script Analysisluau-lsp built in, with a Script Analysis dock for the whole place.
  • Script debuggerBreakpoints, stepping, Watch and Call Stack, in Edit and during Play.
  • Graph modeSee and edit any script as a node graph, Blueprint style.
  • Bytecode dockSee what Luau compiles your script into, live as you type.
  • Format with StyLuaShift+Alt+F formats the open script, no install needed.
  • Find in PlaceSearch and replace in every script of the place, with one undo.
  • Command Bar and OutputRun Luau against the live place, and read Output like in Studio.
  • Luau test runnerRun a place's TestEZ specs headlessly, in the editor or in CI.
  • Security AuditFind remote handlers that trust the client too much.
  • Module require graph betaDraw every require in the place, and spot cycles and broken ones.
  • Script templatesYour own starter scripts in the Model and Script menus.
  • Argon live syncSync with your code editor through Argon, built in.
  • Wally packagesSearch and install Wally packages straight into the place.
  • Loren frameworkfabi's Loren framework, optional and built in.

UI

  • UI EditorA Figma-style canvas for StarterGui, instead of typing UDim2s.
  • Figma importPaste a Figma frame link and get a real ScreenGui.
  • ViewportFrame editingSet up a ViewportFrame's camera and contents visually.
  • Pseudo-localization betaCatch UI that only fits in English, and pull strings into a LocalizationTable.

Animation and avatars

  • Animation EditorKey, curve and preview animations on R15, R6 and Avatar Joint Upgrade rigs.
  • Animation GraphsAuthor and preview Animation Graph state machines natively.
  • Rig BuilderInsert R6 and R15 rigs, mannequins, your avatar or any player's.
  • Auto-rigTurn an unrigged mesh or Roblox model into an R15 rig.
  • Avatar SettingsStudio's Avatar Settings dock, editing the place's AvatarSettings.
  • Accessory Fitting ToolFit a mesh as a rigid accessory or layered clothing, then try it on.
  • Check and upload avatar itemsRun Studio's UGC checks before you upload, then upload for free.

Terrain

  • Smooth terrain and Terrain EditorReal voxel terrain with Studio's whole Terrain Editor toolset.

Renderer

  • Viewport and lightingA native GPU viewport with Roblox's lighting, materials and sky.
  • Effects, adornments and HighlightParticles, beams, trails, fire, smoke, Highlight and the adornment family.
  • Unions and CSGUnions from Studio draw carved, not as boxes.
  • Performance viewTint every part by what it costs, and find the worst offenders.
  • FullbrightSee what you're building in a night place or a dark interior.
  • Quality and calibrationAutomatic quality scaling, quality bands and renderer calibration.

Play and testing

  • Play without StudioHit Play and the real Roblox client runs inside the editor.
  • Test purchasesBuy passes, products and items in a test without spending Robux.
  • Device SimulatorPreview phones, tablets, consoles and headsets, in Edit and in Play.
  • Network SimulatorMake your playtest really lag, on purpose.
  • Controller EmulatorA virtual gamepad that the real client sees.
  • Recorded playtestsEvery playtest is recorded, then replayed in Edit mode.
  • Server Authority placesEditor support for Roblox's Server Authority mode.

Collaboration

  • Team Create with StudioWork next to people in Studio, through the Team Presence plugin.
  • Live co-editing betaShare edits live between RbxNative editors and with Studio.
  • Branch and merge placesThree-way merge of place files, with real conflict resolution.

Cloud and publishing

  • Home and templatesStart a place from a template, your recent files or your games.
  • Save and publish to RobloxUpload to Roblox from the File menu, or make a new experience.
  • Version historyBrowse, search, open and restore any saved version of a place.
  • Game SettingsStudio's Game Settings dialog, and it tells you where each value lives.
  • DataStore browserBrowse and edit DataStores and MemoryStores from the editor.
  • Every place of a game in one windowOpen all the places of an experience together.
  • Update planning betaCountdown icons on autopilot for your next update.

AI and MCP

  • MCP server for AI assistantsLet Claude, Cursor or VS Code read and edit the place you have open.

Plugins

  • Studio pluginsReal Roblox Studio plugins run inside the editor. F3X and Archimedes work.
  • Popular pluginsOne-click install for free plugins checked to run here.
  • Native plugins (Luau and WebAssembly)Write plugins for RbxNative itself, in Luau or WebAssembly.

Themes and accessibility

  • Themes and theme builderRestyle the whole editor, live, and build themes in your browser.
  • Studio SettingsEvery preference in one window, Alt+S.
  • Dock layoutsDrag, split, stack and float docks, then save the layout by name.
  • Auto-RecoveryA crash costs minutes of work, not everything since your last save.
  • Keyboard and accessibilityThe whole editor works from the keyboard, at any UI scale.
  • Discord Rich PresenceShow what you're working on in your Discord profile.

Platform

  • Native on LinuxNo Wine, no VM. Installs in one line and updates itself.
  • Windows and macOSExperimental builds for Windows 10/11 and Apple Silicon Macs.
  • Command-line toolsScript the editor, and run Luau, audits and merges from a terminal.
  • Viewer in the browserThe same renderer, running on WebGPU in a browser tab.

Coming next

Not shipped yet, so no pages for these. They're on branches being worked on right now.

Coming in 0.2.2

  • AI assistants page in Settings: connect Claude Code, Claude Desktop, Cursor or VS Code from one page, with a copyable setup and a self-test. The MCP server becomes a normal setting, on by default, instead of a beta.
  • MCP building skills: guides an assistant reads before it builds: low-poly modeling with Parts and unions, modular kits on a stud grid, colour palettes and materials, lighting presets per mood, level design with real Roblox measurements, and bringing CC0 kits in. Kenney's kits are the style reference.
  • A performance pass: less CPU at rest, faster Explorer and Properties on big places, nothing blocking the window, so it runs smooth on low-end PCs too.
  • Pre-publish check: one button before you publish. It runs the Security Audit plus broken asset ids, deprecated calls like wait(), unanchored parts that fall at start, DataStore calls without pcall, and huge unions or part counts.
  • Free model kits in the Toolbox: browse CC0 packs (Kenney, Quaternius, Poly Pizza's CC0 section) and import them in one click, scaled to studs with pivots set.
  • Shareable bug repros: export a recorded playtest, send it, and your teammate watches exactly what happened.

Coming in 0.3.0 (beta)

  • Local Run: our own runtime for Roblox games, from scratch, so you can run a place without the Roblox client: server and client scripts, physics, Humanoids, your avatar, GUIs, sounds and several local players. It'll ship as a beta next to the real Play, which stays the reference.
  • Offline mode: make a place available offline and keep working, assets and avatar included, with no connection.
  • Several players and the server in one window: each one in its own tab, all running at once.
  • Integration tests: the Luau test runner running whole-game tests on Local Run, server and clients included, from the same CI command.
  • Remote inspector: every RemoteEvent and RemoteFunction call per player, with size, rate and the script that fired it.
  • Bot players: 20 to 50 scripted players on a local server to see when it falls over, before launch.
  • Leak finder: connections never disconnected, instances piling up and tables that keep growing over a session.

The roadmap has the full list of what's planned.
