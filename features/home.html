Features / Cloud and publishing

Home and templates

Start a place from a template, your recent files or your games.

Launching RbxNative without a file opens Home: New, Recent and your games.

How to use it

  • New has Studio's Baseplate, Classic Baseplate and Flat Terrain (measured from Studio), plus a Loren project and your own templates.
  • File › Save as Template saves the open place as a template with a viewport shot. Right-click a template to delete it.
  • Recent shows the Roblox place each file came from, with an icon view and a menu per place (including Archive).
  • My Games lists your experiences and your groups', from a cache.

Compared to Studio

  • Save as Template was asked for on the DevForum since 2019, Studio still doesn't have it.
