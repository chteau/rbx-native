Features / Cloud and publishing

Every place of a game in one window

Open all the places of an experience together.

File › Open Game (or a game card's "Open every place as one game" on Home) opens every place of an experience in one window.

How to use it

  • A Places bar swaps the place on screen instantly. Each keeps its own undo history, selection, camera and script tabs.
  • Find in Game searches every script of every place, and replaces with a preview in one undo step.
  • Publish all places at once.

Compared to Studio

  • Studio edits one place per window.
  • The game is a .rbxgame manifest next to the place files, nothing gets written into the places.
